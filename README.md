# Horabik · Auto Serwis — demo

Minimalistyczna strona demo dla **Krzysztofa Horabika** — Auto Serwis, Myślenice (elektromechanika samochodowa od 2000 r.).

## Klimat

Czyste, lekkie, ascetyczne. Jeden font (Geist + Geist Mono), jeden akcent (elektryczny niebieski `#1B3CE0`), zero gradientów, zero teł, jeden 6-pikselowy translate w revealu. Wszystko inne to typografia, linie i przestrzeń.

## Stack

- statyka: `index.html` · `styles.css` · `app.js`
- bez frameworka i build-stepu
